## <span style="color:#6b35aa">Simulation</span>

Now that that we have a pretty good idea about what we want our robot to look like and how it will function, we have started working on setting up the preliminary cad model in our simulation software. While the prelimanary CAD is not final and the robot would probably end up looking different, it is a good starting point to begin programming the robot's movements and functionality in the simulation environment. This will allow us to start testing and refining our code early in the build season, which is crucial for ensuring that our robot performs optimally during competitions.

This year the software used for simulation is the same as last year. The software and libraries we use are:

- OvertureLib: Our own library, in C++, used to publish the simulation data to network tables, via wrappers for the TalonFX, Pigeon2 and CANCoder CTRE classes. The library runs on our robot code and by using the wrappers the data is published automatically to network tables when it detects simulation mode is enabled.
- Maple-Sim: Runs the simulation environment in a secondary WPILib Java robot program. It reads the data from network tables, simulates the robot physics and sends the updated data back to network tables.
- AdvantageScope: Used for visualization of the robot and field. It reads the data from network tables and animates the robot based on the data received.
